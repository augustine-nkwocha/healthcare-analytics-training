# Healthcare Analytics Training

This repository contains my structured public health and clinical data analytics training projects.

## Focus Areas

- Health data governance
- Epidemiology
- Data cleaning and validation
- Surveillance analytics
- SQL indicators
- Clinical data management
- Reproducible pipelines

## Project Structure

- data/raw: original datasets
- data/interim: intermediate files
- data/processed: cleaned datasets
- notebooks: exploratory analysis
- scripts: reusable Python scripts
- reports: QC reports and stakeholder summaries
- docs: SOPs and governance notes
- tests: validation checks
